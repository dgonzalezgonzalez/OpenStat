## Notes

* The dispatch inventory is read statically from `openstat/*.py` with
  `ast`; nothing is imported or executed. Naming a command in the
  dispatch table is not a claim that the command is fully implemented.
* Subjects that are help topics rather than commands (postestimation
  pages, option glossaries, prefix variants such as `bayes: regress`)
  are part of the index but are not commands OpenStat can implement.
